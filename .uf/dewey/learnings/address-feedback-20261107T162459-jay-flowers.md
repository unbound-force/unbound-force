When PR feedback prescribes a remediation mechanism that is verifiably unrecoverable — source sessions absent from the local opencode database, dispatch artifacts absent from every local clone, PR authored on another machine — the structurally sound resolution is the in-repo precedent for the identical defect, not literal compliance and not a stalled fix: preserve each verified prefix verbatim, complete the content from the public source material the artifact itself cites (PR #968's 15 truncated learning prefixes all fragment-match PR #949's inline review findings), and land terminal punctuation per the accepted cd603598 fix on merged PR #949. Precedent-following keeps the fix diff reviewable (pure addition after a preserved prefix) and each completion grounded, where insisting on the named re-export mechanism would block a required-before-merge item on data that no longer exists anywhere reachable.
