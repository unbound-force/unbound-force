Extending a class-wide permission gate to glob every persona surfaces pre-existing non-conforming members that the same change must then fix — in pairs. On unbound-force, divisor-curator.md carries gh allows with no terminal metacharacter denies, and its scaffold mirror internal/scaffold/assets/opencode/agents/divisor-curator.md is pinned byte-identical by drift-detection tests (TestCanonicalSources_AreEmbedded): fixing the canonical file alone fails the suite. Plan the canonical-plus-mirror fix in the same change as the gate extension, or the extended gate cannot ship green.
