In GitHub Actions, a shared 'changes' detection job that needs fetch-depth: 0 to compute a PR merge-base diff still performs that full-history clone on push events, where it typically short-circuits to a constant output without diffing. Guard the checkout (conditional fetch-depth, or skip the diff-only work on push) to avoid paying a full clone on every push to the default branch.
