A CI required-check aggregate should assert exact expected conclusions by scope, not just success-or-skipped: require each gated job to be `success` when the scope code is true and `skipped` when it is false, and fail on any unexpected scope code. This catches a gated job that ran when it should have skipped (and vice versa) while keeping the single required check fail-closed on both sides. The prior success-or-skipped form cannot tell a correctly-skipped chore PR from a code PR that was wrongly skipped.
