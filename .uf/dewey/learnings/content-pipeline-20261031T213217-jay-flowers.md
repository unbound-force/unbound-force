AGENTS.md's documentation-gate phrasing ("file a documentation issue against the current repo") restates the gate more narrowly than the org constitution's Cross-Repo Documentation rule, which requires an issue in unbound-force/website for user-facing changes before PR merge. A change whose documentation phase cites only the AGENTS.md phrasing plans one issue where two are required, and the constitutional website issue is silently dropped. Established practice (unbound-force PR #744): file both the in-repo docs issue and the unbound-force/website issue. When authoring a change's documentation tasks, derive the issue obligations from the org constitution's Development Workflow section (Cross-Repo Documentation), not from AGENTS.md's restatement alone.
