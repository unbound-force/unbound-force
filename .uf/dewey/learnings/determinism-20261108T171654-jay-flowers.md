A threshold-gated eligibility or mode-selection procedure added to a command file is mechanical instruction even when its threshold values are judgment calls: the values belong inside the extracted tool as constants (DE-006), while the evaluation procedure — fetch, parse, compare, branch, render the mode line — must ship as the executable tool in the same increment (DE-001/DE-005). Documenting a tool extraction as a design.md risk entry or 'Determinism-gate follow-up' does not exempt the new prose: the determinism pack governs new and modified instruction with no deferral clause, and AGENTS.md maps determinism-gate violations to CRITICAL severity. Observed on PR #993's /uf.review-pr Step 3.11 re-review evaluator (light-check-vs-full-council gate over a gh compare fetch, 200-line threshold, path list, and prescribed mode output) — feasible-tool precedent was already present in the same plugin suite (fetch_pr_checks performs CI eligibility classification).
