The unbound-deferral adjudication (PR #993) extends beyond newly-authored choreography: a change that rewrites an existing mechanical procedure's constants (e.g., a schema-conformance update to an artifact-recording rule) while narrating the extraction as a design.md Non-Goal ("a follow-up can extract it") still needs the follow-up bound to a tracked issue or a tasks.md entry in the same change. Verified on PR #1007 — uf.address-feedback Section 4.7's recording rules were rewritten for feedback-triage 1.1.0 while the artifact write (round-number scan, atomic write, envelope) stayed hand-choreographed; the design's Non-Goal named no issue and tasks.md carried no extraction task. The added-vs-modified distinction calibrates how the finding is framed, not whether the follow-up must be bound.
