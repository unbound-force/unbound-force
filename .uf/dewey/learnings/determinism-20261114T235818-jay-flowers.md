Mechanical classification cores in command gates are DE-001 violations even when the gate also contains judgment; the twice-test passes for filtering/selection/comparison/conjunction/mapping. The review-dispatch plugin's resolve_review_mode is the shipped extraction precedent and natural extension point (already finds current user's latest review, compares against the head commit, returns prior findings). A posting-gate sibling would take (reviews, viewer login, current verdict, frozen head_sha) and return the selected prior review (id, html_url, commit_id, submitted_at), a commit_matches_head boolean, and prior findings for the set comparison. Only the semantic fragment (deciding whether the finding set changed by matching prior findings against current findings) stays in prose. Prose classification also grows commands already over token budget (~13.7k self tokens vs 8000 IL-030), the scarce-context cost Constitution Principle VI exists to prevent.
