OpenSpec tasks.md files with [P] tasks plan swarm-path parallel delegations but routinely omit task_classification, and deterministic verification tasks (run make check, make lint-instructions) name make targets in prose — which is not the delegation contract's carrier. The skill parameter on uf_delegate_command accepts a repo-root file (Makefile) or repo-relative script path, not commands; replicator_forge_spawn_subtask carries the same fields for [P] spawns. Spec-stage review should require classification annotations (judgment for authorship tasks, deterministic for exact-command verification with a contract-compliant reference or substantive absence reason) so spawn-time contracts are authored rather than improvised.
