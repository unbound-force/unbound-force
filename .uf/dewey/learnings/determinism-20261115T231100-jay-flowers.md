OpenSpec tasks.md delegation classifications distinguish how work executes from what it produces: authorship tasks (writing code, tests, or docs whose resulting behavior is deterministic) classify as judgment, because two competent agents produce different text for the same contract; only exact-command work (run checks, apply transforms) classifies deterministic, and then MUST name the skill or script reference. Clean exemplar: openspec/changes/compaction-storm-detector-sums-compactio/tasks.md (2026-11, unbound-force) — seven judgment authorship tasks producing deterministic tool behavior in delegation-budget.ts/agent-executor.ts, one deterministic verification task naming repo-root Makefile targets check and lint-instructions.
