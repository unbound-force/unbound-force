Agent-threaded tool parameters that require a scoped selection over prior tool results ('the most recent envelope of THIS phase's own delegations — never reach back to an earlier phase's') drag existence checks and anti-reach-back guards into command prose: a parameter-fill rule with enumerated conditions is DE-001 mechanical instruction, not argument threading. The durable alternative: derive the value in the consuming tool at call time (resolveInheritedBudget-style) or record it durably at computation time so the consuming tool reads it. The selection rule then never enters instruction text, and the value survives session resumes where in-context memory is unreliable.
