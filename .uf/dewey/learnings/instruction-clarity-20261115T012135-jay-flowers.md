When instruction prose defines a classification term with a qualified predicate (e.g., "findings have not materially changed") and then branches on restated conditions, the branch parentheticals must be exact logical complements of the definition. Dropping the qualifier in a branch heading ("findings unchanged") leaves boundary states that no branch matches, so two agents can route the same state to different outcomes.
