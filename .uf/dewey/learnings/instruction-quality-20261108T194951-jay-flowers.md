An invocation doctrine for a shared repo tool lives in three carriers that must move together: the prose command, the frontmatter bash allow, and the graceful-degradation row naming the tool path. PR 959 pinned wrapper-only linter invocation into divisor-linguist.md (prose + permission block + guard test) while its own new divisor-determinism.md carried node-direct invocation in all three carriers — a second doctrine shipped inside the same PR that hardened the first, undetected because the guard test reads only the exemplar persona file. When authoring or reviewing a persona or command that invokes a tool with an established wrapper or canonical entrypoint, check every carrier of the tool's path: the command, the permission allow, and the degradation table must name the same invocation surface.
