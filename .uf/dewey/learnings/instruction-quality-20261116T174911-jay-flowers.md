When command prose defines multiple terminal states for one tool result, give each state a lexically distinct name. In uf.address-feedback, the complete:false definition added 'the skip branch' (issue filing fails; the run ends at Section 4.6 and Section 4.7 must not run) beside the existing 'skip-posting path' (the author declines posting at Section 4.5; Section 4.7 runs with null FILE fields) — near-homonymous labels for opposite terminal behavior, with 'skip' already meaning idempotent re-run skipping elsewhere in the same file. Flow labels that share a head noun conflate under context compression; name terminal flows by cause (e.g. 'failed-filing branch') so each resolves uniquely.
