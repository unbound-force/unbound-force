When implementing OpenSpec changes in the unbound-force repo, tasks generated by /opsx-propose may reference external tools (openspec CLI, specify init) that do not exist in this repo. The openspec CLI is invoked by `uf init` via `initSimpleTool` but its source code lives elsewhere. Tasks referencing these tools should be marked N/A and adapted to what is actually implementable: updating .openspec.yaml directly, updating scaffold templates, and modifying command files like uf.finale.md.
