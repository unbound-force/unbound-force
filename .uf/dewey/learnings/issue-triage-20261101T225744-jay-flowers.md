Docs-labeled and tutorial-labeled issues opened for the same underlying change are complementary content-pipeline artifacts, not duplicates. Docs issues track reference-documentation sync (what changed, which pages need updating); tutorial issues track guided workflow walkthroughs (audience, structure, prerequisites). In triage, keyword-overlap duplicate candidates across these two labels — e.g., a docs issue and a tutorial issue for the same ported slash command — must be verified for distinct labels and distinct deliverables before either is marked duplicate. When both are valid, recommend cross-referencing the pair so the tutorial covers the end-to-end workflow and decision points while the docs issue covers command-level reference detail.
