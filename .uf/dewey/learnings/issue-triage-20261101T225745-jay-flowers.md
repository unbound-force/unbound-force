In unbound-force repositories, the documentation gate produces a docs-tracking issue for each user-facing change (for example, issue #856 "docs: /uf.rebase-pr ported command" for the port-uf-rebase-pr change). Follow-on tutorial issues for the same command keyword-collide with these gate issues in duplicate searches but serve complementary scopes: the gate issue tracks reference documentation for the change, while the tutorial issue requests a task-oriented walkthrough. When triaging documentation issues, compare scope (reference vs. tutorial) before classifying as duplicate, and cross-reference related pairs so the two efforts do not produce overlapping prose.
