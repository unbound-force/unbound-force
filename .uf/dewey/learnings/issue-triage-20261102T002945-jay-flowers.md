Triage pattern for phase-structured migration issues: the umbrella issue a phase issue references will surface as the top duplicate candidate in searches — an explicit "Umbrella: #N" line in the issue body distinguishes intentional hierarchy from accidental duplication. Phase issues that (a) state a verifiable done-when criterion, (b) enumerate their in-scope surfaces, and (c) explicitly defer out-of-scope work to a named later phase triage cleanly as VALID tracking issues with no split recommendation needed, because the author already performed the split at authoring time.
