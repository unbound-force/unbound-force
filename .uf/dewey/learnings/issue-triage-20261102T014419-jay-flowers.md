Deferred content-pipeline recommendations from review councils in unbound-force/unbound-force arrive as tracking issues with a distinctive shape: a trigger condition tied to an epic close ("when #716 closes"), a target artifact in the unbound-force/website repository, the `blog` label, council provenance (curator run id plus dispatch correlation id), and a verifiable evidence list. These are valid deferred-action items and must not be conflated with docs-coverage sync issues (e.g. #791, #781, #834), which track documentation gaps for already-shipped changes. In duplicate searches, the distinguishing signals are the epic-gated trigger and the future-tense content deliverable versus a present-tense documentation update request.
