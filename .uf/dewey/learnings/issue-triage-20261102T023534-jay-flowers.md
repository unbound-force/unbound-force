Triaging migration-tracking issues in this org: an umbrella decision comment can supersede an issue's original workflow decision (issue-only tracking → Speckit spec routing per AGENTS.md's >=3-story/cross-repo strategic tier) without invalidating the issue — the issue remains the execution tracker while the spec becomes the artifact of record (observed: #714 → umbrella #797, spec #799). Read all comments before judging body-only consistency: stale version figures corrected by verified comments (e.g., stale @opencode-ai/plugin 1.4.10 corrected to verified 1.19.0 in both .opencode/package.json and the scaffold mirror) do not invalidate an issue when the correction is cross-checkable against AGENTS.md. Distinct-phase siblings under one umbrella (Phase 1 core vs Phase 2 scaffold) are related work, not duplicates.
