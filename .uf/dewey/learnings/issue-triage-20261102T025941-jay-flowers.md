Prose-to-tool extraction issues under a parent tool-extraction epic (the unbound-force #659 Phase 2 pattern) triage efficiently against three determinism-pack checkpoints: (1) DE-001 — the extracted procedure is mechanical (git choreography, regex sanitization, template rendering), with judgment steps (human confirmation gates, conventional-commit classification) explicitly left in command prose; (2) DE-004 — the issue carries a measurable token/line delta instead of an unsupported efficiency assertion; (3) DE-006 — the tool contract keeps judgment at its boundary, accepting judgment products (approved description text) as validated parameters. Issues satisfying all three, whose keyword-search duplicate candidates are siblings covering distinct tools under the same parent epic, are VALID non-duplicate enhancements. Documentation-gate shortcut for this issue class: extractions whose acceptance criteria demand behavior parity (user-facing behavior unchanged) qualify for the internal-refactoring exemption from the documentation-issue gate, and a single family-level docs issue covering the expanded tool set satisfies content-pipeline tracking for the whole extraction batch.
