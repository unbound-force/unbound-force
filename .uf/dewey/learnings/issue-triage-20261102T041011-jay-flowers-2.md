Triage pattern for retro-bot "add guidance to AGENTS.md" issues: verify the premise against the current AGENTS.md section, then apply the determinism-pack boundary before suspecting a Principle VI conflict — guidance instructing agents to recognize and reuse existing patterns (e.g., extend a table-driven test block such as guardrailBlock rather than write a standalone test function) is judgment/evaluation work, which DE-001 explicitly leaves in prose; it is not mechanical instruction requiring tool extraction. Such issues are VALID enhancements when they carry verifiable evidence (PR/review-comment/fix-commit links), a quantified rework cost, measurable validation criteria, and repo-local scoping — sibling hero repos maintain their own Testing Conventions sections independently, so no cross-repo sync obligation arises from a meta-repo AGENTS.md conventions addition.
