Verdict-level acceptance criteria stated as negations of a reading ("the verdict does not read as unqualified APPROVE") are not eval-assertable: the criterion admits several verdict/report renderings and the eval author must guess which ones satisfy it. Name the observable instead — the allowed verdict values ("the verdict is REQUEST CHANGES or APPROVE WITH ADVISORIES") or a distinct report state — and define what resolves the conditioning state (e.g., what marks a deviation finding resolved), since "while X is unresolved" is otherwise unbounded. Every AND-clause in a Given/When/Then scenario is a pinning obligation; an AND-clause that cannot be pinned deterministically is a silent-regression window.
