When a security fix ships as interim prose choreography because the linked issue prescribed that form (PR #1024 closing #1011), the change record must still carry the Constitution Principle V/VI trade-off note plus a tracked tool-extraction follow-up reference — the Conflict Resolution rule makes the written justification a MUST, not a nicety. Without the record, the deferral is invisible: the runtime guard for the injection class stays prose-enforced and regressible through prompt drift, and remediated command families diverge in shape for the same vulnerability class (#1007's tool-routed post_feedback_replies vs #1024's prose choreography), inviting the weaker pattern to be copied into new templates.
