A convention test that names its subject by hard-coded path enforces the convention for exactly that path — every other member of the class silently escapes. PR 959 added the divisor-determinism persona with bash allows while both persona-invariant tests in instruction-lint-preflight.test.ts ("routes the make target and the persona through the wrapper", "keeps the persona's metacharacter denies after every bash allow") read only divisor-linguist.md, so the new persona shipped with no terminal metacharacter denies and direct-node linter invocations in the same PR that hardened and guarded the precedent; widening the test to a glob then surfaced divisor-curator as a second, older unhardened member. When a convention governs a directory of files (persona frontmatter, pack files, command manifests), the guard test must discover its subjects the same way production code does — glob the directory and filter for the feature (e.g., every .opencode/agents/divisor-*.md with a bash permission block) — never pin one exemplar. The repo's TestReviewerCapabilities_RepoLocalPersonasEnrolled is the model: it iterates the agents directory and fails on any unenrolled persona.
